# TP d'Analyse Numérique 

Ces activités illustrent les notions abordées dans cette discipline. 
Ce cours se découpe en plusieurs chapitres. 

Chapitre 1 : L'Intégration Numérique 
Nous étudions des méthodes de calculs qui permettent d'approcher des intégrales difficiles à résoudre afin d'obtenir un résultat approché.
Nous nous intéressons donc à plusieurs méthodes différentes notamment celle de Newton-Côtes, Gauss-Legendre ou encore Gauss. 
Elles établissent des quadratures plus simples à calculer.
Nous étudions également les erreurs autour de ces méthodes afin d'identifier lesquelles sont plus efficaces en fonction du problème à traiter.
